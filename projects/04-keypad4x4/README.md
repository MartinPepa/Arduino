## Modules implemented

#### Arduino:
- Arduino Pro-Mini 5V
- Module CP2102: UBS to serial TTL converter (for code upload)

#### Modules/Sensors:
- LCD Display 16x2 with I2C interface module (Inter-Integrated Circuit).
- 4x4 Matrix Membrane Keypad.
- BMP280.
- DHT11.
- Protoboard.

#### Extras:

- Dupont wires:
  - M-F: 20.
  - M-M: 0.
  - F-F: 10.
- Resistors:
  - 1 resistor: 10 KOhm.
  - 1 resistor: 20 KOhm.
